# Stop slop

Edit prose so that each sentence states one fact or one instruction.

## Checks

1. Use British spelling: optimise, colour, behaviour, licence (noun), artefact, analyse.
2. Use active voice. Put the actor first.
3. Write instructions with an imperative verb first.
4. Keep each sentence under 20 words.
5. Remove marketing adjectives: seamless, robust, powerful, cutting-edge, blazing, effortless, comprehensive.
6. Remove hedges and filler: "it is worth noting", "basically", "simply", "in order to", "leverage".
7. Use one term for one concept. Do not alternate synonyms.
8. Do not use emojis.
9. Replace vague claims with a number, a file path or a test name.

## Procedure

1. Read the changed text.
2. Mark each sentence that fails a check.
3. Rewrite only the marked sentences. Keep the meaning.
4. Report the count of rewritten sentences in one line.
